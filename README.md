🖼️ Unlimited Glimpse — Image Search App
Overview

An image search application powered by the Unsplash API that dynamically fetches and displays images in a responsive grid layout.

✨ Features
Search for images
Responsive image gallery
Hover animations
Open full-resolution image on click
Dynamic image rendering
Keyboard Enter support
Accessible image alt text
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Unsplash API
Fetch API
📚 Concepts Practiced
API integration
Arrays and loops
forEach()
Dynamic DOM creation
Working with nested objects
Grid layouts
Event listeners
Responsive UI design
🚀 Goal

This project was created to improve my understanding of APIs, dynamic rendering, arrays, loops, and interactive frontend application design.
